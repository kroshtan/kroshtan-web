# private/

Extra context for the "Can I help with this?" assistant: Markdown (`.md`) or text (`.txt`) files that describe
work, projects or skills not on the public site. Everything in this folder except this README is gitignored.

Information from these files may appear in answers, so put nothing here that must stay confidential.

Locally, drop files here. On Render, add each file as a Secret File and set `PRIVATE_DIR=/etc/secrets`; see the
README in the repository root.
